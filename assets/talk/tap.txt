# Lines for a tap on the voice's line on the main screen: lang.cell.voice|line.
# A phrase is greet + name + self + invite, a line from each cell, never the same one twice in a row.
# Plain words only: a joke that comes back is no longer a joke.
# Taps in a row cool it down: the fourth drops greet, from the fifth on only the flat line, a little slower.
# Voices: 1..5 in the order of the troupe.
